# Sokak Lambası ile Konuşan Kedi

## Proje Tanımı
Gece yarısı, sokak lambalarının altında toplanan kedilerin, lambalarla yaptığı derin felsefi sohbetleri belgeleyen bu sistem, insanlığın kediler hakkındaki yanlış algılarını düzeltmeyi amaçlar. Kediler sadece miyavlamaz, onlar lambalarla kuantum dolaşıklık içindedir.

## Kurulum ve Çalıştırma
```bash
python kedi_lamba_sohbeti.py
```

Program, rastgele bir sohbet üretecek ve kedinin lambaya ne söylediğini size aktaracaktır. Lütfen sohbeti yargılamayın, kediler çok hassastır.

## Bilimsel Temel
- Lambaların frekansı kedilerin mırlama frekansıyla rezonansa girer
- Her miyav, aslında bir şiirdir
- Sokak lambaları, evrenin en iyi dinleyicileridir

## Sorumluluk Reddi
Bu program çalıştırıldıktan sonra kediniz size kızgın bakabilir. Normaldir.
